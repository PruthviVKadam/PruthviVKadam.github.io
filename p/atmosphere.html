City air quality, 24 hours ahead — and honest about it.

A reliability-first air-quality explorer: scrub a 24h timeline on a live map and watch PM₂.₅ / O₃ / NO₂ forecasts update — built to fail soft when public APIs go dark and to only serve a model that genuinely beats its baselines.

Open the live demo → View code

Problem

A forecast app is only as trustworthy as its honesty: most demos overstate accuracy, hide stale data, and crash when a public sensor API goes dark.

Approach

Per-pollutant, per-horizon HistGradientBoosting (direct multi-step) over OpenAQ/AirNow/Open-Meteo, scored by walk-forward CV against persistence and seasonal baselines, behind a resilient FastAPI + MapLibre frontend.

Result

A model is promoted only for a pollutant it beats at every horizon; everything carries a freshness stamp and degrades soft. Honest by construction.

Insights

What it shows

"Beats baseline" is earned, not assumed. O₃ and NO₂ clear both baselines at every horizon and are served by the model; PM₂.₅ only ties the 24h "same hour yesterday" echo, so it is deliberately NOT promoted — the API serves its persistence forecast with beats_baseline=false.

Reliability is the headline feature. Every external call has timeout + retry + circuit breaker + cache; every data-bound component has loading / empty / error / stale states. No silent failures, no infinite spinners.

Freshness is non-negotiable. A data_as_of stamp flows from ETL to UI, and interpolated values are flagged — the user always knows how fresh (and how real) what they're seeing is.

Direct multi-step, not recursive. A separate model per horizon predicts the change from the current value — avoiding the error compounding that sinks recursive forecasts.
