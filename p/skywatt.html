Sky image in, solar power out.

A short-term PV nowcaster: a CNN reads a stack of sky images, a cloud-segmentation overlay blooms, and a physically-bounded power meter swings — beating persistence exactly when a cloud rolls across the sun. React + FastAPI, served on plain CPU.

Open the live demo → View code

Problem

Solar output swings the instant a cloud occludes the sun. "Next = current output" (persistence) is a strong short-horizon baseline; beating it needs to see the cloud coming.

Approach

A CNN over a 3-frame sky-image stack + a context MLP predicts the clearness index; a physics layer bounds every output (0 ≤ power ≤ clear-sky ceiling, zero at night). Served CPU-only behind a timeout.

Result

SkyFusion beats persistence on overall error and on the cloud-transition slice that actually matters — at every horizon — with predictions that can never violate physics.

Insights

What it shows

The image is the edge. Clouds advect with a per-day wind, so the cloud about to occlude the sun is visible upwind in the frame — solvable by a vision model, invisible to persistence.

Physics is a guardrail, not a hope. Every prediction passes one bounds layer; a value that would be negative, above capacity, or non-zero at night is clamped and the reason reported — never shown raw.

Benchmark on the slice that matters. Average error flatters everyone on calm hours; the honest test is the cloud-ramp events, where SkyFusion wins at every horizon.

Ships on CPU. Training may use a GPU, but the served model runs on plain CPU behind a timeout — the repo (and this demo) run without a GPU.
