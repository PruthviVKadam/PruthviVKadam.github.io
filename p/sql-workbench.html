Problem

Approach

Run DuckDB in the browser via WASM over a committed synthetic dataset, with a CodeMirror editor and 10 ramped challenges; every solution is executed and asserted in CI.

Result

Insights

What it shows

WASM removes the backend entirely. A full analytical SQL engine runs client-side — no server to provision, pay for, or keep awake.

Challenges are CI-verified. Each of the 10 solutions is executed through DuckDB and asserted on column names + frozen row counts, so the "answers" can't silently rot.

Reliability is a feature. Unlike a sleeping demo, a static Pages app is always instantly live — the right call for a tool reviewers click cold.
