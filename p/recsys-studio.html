Recommenders · Ranking · Live

Recommenders judged by ranking, not RMSE.

Implicit-feedback models — Popularity vs item-kNN vs ALS — scored with NDCG / Recall / MAP on a leakage-free temporal split, plus coverage & novelty so the board can't be gamed.

Open the live demo → View code

Problem

Most portfolio recommenders report RMSE on a random split — which rewards a number nobody ranks by and leaks the future into the past.

Approach

Treat MovieLens as implicit feedback, split by time at one global cutoff, and compare Popularity → item-kNN → ALS behind one interface, scored by ranking + coverage + novelty.

Result

An honest leaderboard with a "because you liked X" explanation — and a clear trade between accuracy and catalog coverage.

Insights

What it shows

A non-personalized baseline is hard to beat. On a strict temporal split, recommending the most-liked unseen items wins raw accuracy — MF doesn't clear that bar, and saying so is the point.

"Best" depends on the metric. ALS trails on accuracy but covers 7.5× more of the catalog at the highest novelty — an engagement-vs-discovery trade a single number hides.

The split decides the story. A global temporal cutoff leaves only 94 honest test users; a per-user split would inflate that but re-introduce the leak the project exists to avoid.
