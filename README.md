# PruthviVKadam.github.io

Source for my portfolio hub — a single-page, zero-build static site on GitHub Pages.

**Live:** https://pruthvivkadam.github.io

## What this is
A hub that links to interactive demos of each portfolio project (A/B testing, credit risk,
RAG, forecasting, SQL, BI). Recruiters click one URL; everything is playable.

## Local preview
```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Deploy
Push to `main` — GitHub Pages republishes automatically in ~2 minutes.
